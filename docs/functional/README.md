# Documentación funcional

Consulte el README de cada módulo para conocer su finalidad y los primeros pasos.
Las guías de configuración y uso se encuentran en `docs/functional/` dentro de
cada módulo. Reserve esta carpeta para procesos que combinan varios módulos.

## Elaboración y mantenimiento

El equipo de consultoría de Kernet es responsable de esta documentación. Los
desarrolladores y los agentes de IA pueden preparar una guía inicial y documentar
nuevos procesos o cambios de configuración junto con el cambio correspondiente.

Lea la documentación existente antes de editarla. Conserve el contenido, los
ejemplos y las explicaciones que siguen siendo correctos. Si cambia el
funcionamiento, actualice los pasajes afectados sin eliminar información que
sigue vigente. No reduzca una guía para adaptarla a la brevedad del README.
Consulte con el equipo de consultoría las dudas sobre procesos de negocio.

Explique con el detalle necesario:

- Para qué sirve el proceso, por qué se utiliza y quién lo realiza.
- Qué requisitos y permisos necesita, y dónde se configura o se ejecuta.
- Cómo se realiza cada paso y qué resultado se espera.
- Qué opciones existen, en qué se diferencian y qué consecuencias tienen.
- Ejemplos y resolución de problemas cuando sean útiles.

Mantenga el README como introducción breve y enlace desde él a estas guías.
