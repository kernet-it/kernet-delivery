# kernet-delivery

Kernet delivery addons.

Módulos de Kernet para **delivery**, compatibles con **Odoo 20.0**.
Cada rama `NN.0` contiene los módulos de esa versión de Odoo.

## Primeros pasos

Consulte el README de cada módulo para conocer su finalidad, requisitos y
configuración mínima. La instalación se realiza en el proyecto Odoo que lo utiliza.
